# Atena Tech – Sistema de Gestão Comercial

Projeto de extensão da disciplina de **Lógica e Programação Visual**.
Aplicação em C# (console) que simula as operações comerciais de uma pequena
empresa em transição digital, substituindo o controle manual em planilhas.

## Sobre a Atena Tech
Empresa de tecnologia especializada em soluções de desenvolvimento de software
e inteligência de dados, voltada a pequenas e médias empresas.

## Funcionalidades
- Cadastro e listagem de clientes (com bloqueio de duplicados)
- Cadastro de produtos e consulta de estoque com situação (OK, baixo, esgotado)
- Registro de vendas com baixa automática no estoque
- Desconto de 10% para compras de 10 unidades ou mais
- Relatório de vendas (faturamento, ticket médio, produto mais vendido)
- Reajuste de preços por percentual

## Conceitos de programação aplicados
Variáveis e constantes, operadores aritméticos, relacionais e lógicos,
`if/else`, `switch`, `for`, `while`, `do...while`, vetores e menu interativo.

## Como executar
1. Instale o .NET 6 ou superior (ou o Visual Studio).
2. Clone o repositório: `git clone <link-do-repositorio>`
3. Abra a pasta e execute: `dotnet run`
   (ou abra o projeto no Visual Studio e pressione F5)
